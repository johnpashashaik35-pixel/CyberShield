
# 🛡️ CyberShield

A simple cybersecurity toolkit built with Python, Flask, HTML, CSS, and JavaScript.

## 🚀 Features

- 🔐 **Password Strength Checker** — Checks password strength using basic rules.
- 🔎 **URL Safety Checker** — Identifies some suspicious URL patterns.
- 🧾 **File Integrity Checker** — Generates SHA-256 hashes for selected files.

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Web Crypto API

## 💻 Run Locally

1. Clone or download this repository.
2. Open a terminal inside the project folder.
3. Create a virtual environment:

   ```bash
   py -m venv .venv
   ```

4. Install Flask:

   ```bash
   .venv\Scripts\python.exe -m pip install flask
   ```

5. Start the application:

   ```bash
   .venv\Scripts\python.exe app.py
   ```

6. Open `http://127.0.0.1:5000` in your browser.

## ⚠️ Disclaimer

This project is for educational purposes only. The URL checker uses basic heuristics and cannot guarantee that a website is safe. The password checker is a simple strength estimate, not a complete security audit.
